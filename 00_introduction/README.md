# Setup Tools

Вводный файл по курсу машинного обучения: здесь описаны инструменты, которые понадобятся для работы. Кода в этом разделе нет.

## Зачем нужен этот раздел

Перед тем как решать задачи по машинному обучению, нужно подготовить рабочее окружение: установить язык программирования, основные библиотеки и среду, в которой удобно писать и запускать эксперименты.

## Используемые инструменты

### Python
Основной язык курса. Он простой в написании и имеет богатую экосистему библиотек для работы с данными и моделями.

### Виртуальное окружение (venv / conda)
Изолированная среда для каждого проекта. Библиотеки одного проекта не конфликтуют с библиотеками другого, а набор зависимостей легко воспроизвести на другом компьютере.

### Jupyter Notebook
Интерактивная среда, в которой код, результаты и пояснения лежат в одном документе. Удобна для экспериментов, визуализации и отчётов.

### Основные библиотеки
- **NumPy** — быстрые вычисления с массивами и матрицами.
- **pandas** — загрузка, очистка и анализ табличных данных.
- **Matplotlib** — построение графиков и визуализация данных.
- **scikit-learn** — готовые классические алгоритмы машинного обучения и инструменты для оценки качества моделей.

### Git
Система контроля версий. Хранит историю изменений проекта и позволяет возвращаться к предыдущим версиям.

### Среда разработки (IDE)
Редактор кода для написания скриптов и проектов, например PyCharm или VS Code.
