# DBSCAN: плотностная кластеризация

**Файл:** `dbscan_clustering.ipynb`  
**Данные:** `make_moons`, `make_circles` и `Wine` из `sklearn.datasets`

Исследование алгоритма плотностной кластеризации DBSCAN: выбор параметра `eps` по k-distance plot, сравнение с K-Means на нелинейных данных, влияние гиперпараметров и применение к реальному датасету с анализом шумовых точек.

## Данные

- **`make_moons`** (300 точек, `noise=0.08`) и **`make_circles`** (300 точек, `noise=0.05`, `factor=0.5`): 2D-данные с нелинейными кластерами;
- **`Wine`**: 178 образцов вина трёх сортов, 13 химических признаков. Истинные метки при кластеризации не используются.

Все датасеты встроены в `scikit-learn`, скачивать ничего не нужно.

## Теория коротко

DBSCAN задаётся радиусом окрестности `eps` и минимальным числом точек `min_samples`. Точки делятся на три типа:
- **корневые** (core): в их `eps`-окрестности не меньше `min_samples` точек;
- **граничные** (border): корневыми не являются, но достижимы из корневой;
- **шумовые** (noise): всё остальное, метка `-1`.

Кластер строится из корневых точек и всех плотно достижимых из них. Параметр `eps` выбирают по **k-distance plot**: расстояния до k-го соседа, отсортированные по убыванию; «локоть» на графике показывает границу между плотными областями и шумом.

## Что делается в ноутбуке

### 1. K-Means на нелинейных данных
K-Means с `n_clusters=2` не справляется с «лунами» и «кольцами»: он минимизирует сумму квадратов расстояний до центров, поэтому ищет выпуклые «шарообразные» кластеры с линейными границами.

### 2. Выбор `eps`
Данные масштабируются `StandardScaler`, строится k-distance plot (`k = 5`). «Локоть» около значения 0.27, оно и взято как `eps`.

### 3. DBSCAN на лунах и кольцах
`DBSCAN(eps=0.27, min_samples=5)` на отмасштабированных данных. Результаты показаны на графиках, шумовые точки отмечены чёрными крестиками.

### 4. Сравнение силуэта на `make_moons`

| Алгоритм | Silhouette |
| :--- | :--- |
| K-Means (K=2) | 0.449 |
| DBSCAN (без шумовых точек) | 0.380 |

K-Means получил выше силуэт, но визуально разбиение неверное: силуэт любит компактные выпуклые кластеры и не отражает истинную структуру.

### 5. Влияние гиперпараметров
Сетка `eps` ∈ {0.05, 0.15, 0.3, 0.5, 0.8, 1.5} при `min_samples=5`:
- слишком малый `eps`: кластеры дробятся, много шума;
- подходящий (около 0.3): два правильных кластера;
- слишком большой: кластеры сливаются в один.

### 6. DBSCAN на реальных данных (Wine)
Масштабирование, k-distance plot (`k = 4`), `DBSCAN(eps=2.4, min_samples=4)`. Для анализа шумовых точек их средние значения признаков сравниваются со средними по всей выборке. Заметнее всего отличаются:

| Признак | Среднее по выборке | Среднее у шума | Разница |
| :--- | :--- | :--- | :--- |
| proanthocyanins | 1.59 | 1.87 | +17.7% |
| color_intensity | 5.06 | 4.18 | −17.3% |
| proline | 746.89 | 627.61 | −16.0% |

### 7. DBSCAN и K-Means на Wine
Результаты обоих методов визуализированы в проекции на первые две главные компоненты (PCA) и сопоставлены по силуэту.

## Выводы

- **DBSCAN лучше K-Means**, когда кластеры имеют сложную невыпуклую форму и когда в данных есть шум: он умеет помечать выбросы, а K-Means включает в кластеры всё.
- **K-Means предпочтительнее** на компактных круглых кластерах без шума: он быстрее и проще в настройке.
- **Масштабирование обязательно:** DBSCAN использует евклидово расстояние, и крупные признаки без стандартизации подавляют мелкие.
- Силуэт нельзя напрямую сравнивать между DBSCAN и K-Means: у DBSCAN шумовые точки исключаются из расчёта, а сама метрика благоволит выпуклым кластерам.
- Шумовые точки в Wine скорее необычные образцы (аномалии), чем ошибки данных.
