# Снижение размерности: PCA, t-SNE и UMAP

**Файл:** `dimensionality_reduction.ipynb`  
**Данные:** `digits` из `sklearn.datasets`

Применение методов снижения размерности к рукописным цифрам: PCA как препроцессинг и инструмент интерпретации, t-SNE и UMAP для визуализации, количественное сравнение проекций.

## О данных

- **Размер:** 1797 изображений рукописных цифр 0–9;
- **Признаки:** 64 (изображение 8×8 пикселей, интенсивность каждого пикселя);
- **Задача:** 10-классовая классификация (в работе используется и для визуализации структуры данных).

Датасет встроен в `scikit-learn`, скачивать ничего не нужно.

## Что делается в ноутбуке

### 1. Подготовка
Просмотр примеров цифр и стандартизация `StandardScaler`: перед PCA она обязательна, так как PCA чувствителен к масштабу признаков.

### 2. PCA: сколько компонент нужно
PCA на всех 64 компонентах и график накопленной объяснённой дисперсии (cumulative explained variance ratio):

| Доля дисперсии | Число компонент |
| :--- | :--- |
| 80% | 21 |
| 95% | 40 |
| 99% | 54 |

### 3. PCA для визуализации и интерпретации
- проекция на 2 главные компоненты: PC1 объясняет 12.0%, PC2 9.6%, вместе 21.6% дисперсии;
- **loadings** (нагрузки) PC1 и PC2, показанные как изображения 8×8: какие пиксели сильнее всего влияют на компоненту.

### 4. PCA как препроцессинг для классификатора
`LogisticRegression` на отмасштабированных данных (train/test 80/20):

| Вариант | Accuracy |
| :--- | :--- |
| Без PCA (64 признака) | 0.9722 |
| PCA 95% (40 компонент) | 0.9639 |
| PCA 80% (21 компонента) | 0.9472 |

### 5. t-SNE
Нелинейная визуализация (`perplexity=30`) и эксперимент с `perplexity` = 5, 30, 100: при малом значении кластеры дробятся, при большом сливаются, а структура зависит от параметра.

### 6. UMAP
`UMAP(n_neighbors=15, min_dist=0.1)`: быстрая нелинейная проекция, лучше сохраняющая глобальную структуру.

### 7. Сравнение проекций
Визуальное сравнение PCA, t-SNE и UMAP и количественная оценка через Silhouette Score по истинным меткам:

| Проекция | Silhouette |
| :--- | :--- |
| UMAP | **0.5687** |
| t-SNE | 0.4848 |
| PCA (30 компонент) | 0.1297 |
| PCA (2 компоненты) | 0.0547 |

### 8. Реконструкция из PCA
Через `inverse_transform` восстанавливается одна цифра при k = 2, 5, 10, 20, 40 компонентах: чем больше компонент, тем ближе картинка к оригиналу.

## Выводы

- Для сохранения 95% дисперсии достаточно 40 компонент из 64 (около 63% признаков).
- PCA-препроцессинг даёт небольшое падение accuracy (0.972 → 0.964 при 95%, 0.947 при 80%): на чистом датасете это плата за упрощение модели, на зашумлённых данных сжатие может, наоборот, повысить устойчивость.
- Линейная проекция PCA на 2 компоненты плохо разделяет классы (всего 21.6% дисперсии), а t-SNE и UMAP разделяют их заметно лучше. UMAP показал лучший Silhouette и работает быстрее t-SNE.
- PCA стоит применять как первый шаг при большом числе скоррелированных признаков или для ускорения t-SNE; t-SNE и UMAP использовать только для визуализации.

## Используемые библиотеки

`numpy`, `pandas`, `matplotlib`, `scikit-learn`, `umap-learn`.
