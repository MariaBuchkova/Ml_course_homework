# Полный цикл EDA: цены на жильё

**Файл:** `eda_house_prices.ipynb`  
**Дата:** 06.03.2026  
**Источник данных:** [Kaggle: House Prices — Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)

Разведочный анализ данных (EDA) на датасете о жилой недвижимости города Эймс, штат Айова: от первичного осмотра и очистки до кодирования признаков, визуализации и выводов.

## О данных

Датасет содержит 1460 строк и 81 столбец: 79 характеристик домов, идентификатор и целевую переменную **SalePrice** (финальная цена дома). Признаки делятся на числовые (35 типа int, 3 типа float) и категориальные (43 строковых).

Файл `train.csv` в репозиторий входит.

## Что делается в ноутбуке

### 1. Первичный осмотр
- `head()`, `tail()`, `shape`: структура таблицы;
- `info()`: типы столбцов и заполненность;
- `describe()`: статистика для числовых и строковых признаков.

### 2. Пропуски и дубликаты
- подсчёт количества и процента пропусков по каждому столбцу;
- проверка полных дубликатов (их нет);
- удаление единственной строки с пропуском в `Electrical`;
- удаление столбцов, где пропусков больше 80% (`PoolQC`, `Alley`, `MiscFeature` и другие).

### 3. Заполнение пропусков
Для каждого признака способ выбран осознанно:

| Способ | Признаки | Почему |
| :--- | :--- | :--- |
| Среднее | `LotFrontage` | распределение близко к нормальному |
| Медиана | `LotArea`, `MasVnrArea` | есть выбросы и большой разброс |
| Константа `NoFireplace` | `FireplaceQu` | пропуск означает отсутствие камина |
| Мода | остальные категориальные | самое частое значение |
| Год постройки дома | `GarageYrBlt` | гараж логично считать построенным вместе с домом |

### 4. Статистики числовых признаков
- минимум, максимум, среднее, медиана, мода;
- перцентили 5%, 25%, 50%, 75%, 95%;
- дисперсия, асимметрия и эксцесс, с разбором ключевых признаков `LotArea`, `OverallQual`, `OverallCond`.

### 5. Кодирование категориальных признаков
- **One-Hot Encoding** (`pd.get_dummies` с `drop_first=True`) для признаков с небольшим числом категорий;
- **Label Encoding** не применяется: все категориальные признаки номинативные, порядка у них нет;
- **Feature Hashing** (10 признаков) для столбцов с числом уникальных значений больше 13.

### 6. Генерация новых признаков
- `TotalSF`: общая площадь (подвал + 1-й этаж + 2-й этаж);
- `PricePerSF`: цена за квадратный фут;
- `Neighborhood_grouped`: районы с долей меньше 2% объединены в категорию `Other`.

### 7. Визуализация
Используются `matplotlib`, `seaborn` и `plotly`:
- гистограммы с KDE: распределения признаков;
- scatter plot: зависимость признаков от цены;
- box plot: поиск выбросов;
- count plot: частоты категорий;
- heatmap: корреляции с `SalePrice`.

## Основные выводы

- Распределение `SalePrice` скошено вправо: есть заметное число дорогих домов, сильно выбивающихся из основной массы.
- `OverallQual` (общее качество дома) — самый важный признак, корреляция с ценой около 0.8.
- Созданный признак `TotalSF` оказался очень полезным и работает лучше отдельных площадей.
- В `LotArea` очень высокий эксцесс (около 203): много экстремальных выбросов.

### Гипотезы
- Район сильно влияет на цену: средний дом в хорошем районе может стоить дороже отличного дома в плохом.
- У подвала важнее состояние и отделка, чем сам факт наличия.
- Редкие категории лучше объединять в `Other`, чтобы модель не переобучалась на единичных примерах.

### Что делать дальше
- **Модель:** XGBoost или Random Forest, они хорошо работают с такими данными и устойчивы к выбросам.
- **Преобразования:** логарифмировать `SalePrice` и `LotArea`, чтобы приблизить распределения к нормальным.
- **Отбор признаков:** оставить топ-20 по корреляции, остальные могут давать шум.
- **Метрика:** RMSE.

## Помощь AI

- **Что подсказал AI:** Feature Hashing, разницу между `nunique()` и `unique()`, `fillna(0)` для подвала, группировку редких категорий.
- **Что сделано самостоятельно:** подбор порогов (2% для редких категорий, больше 13 уникальных значений для хеширования), проверка новых признаков на корреляцию, установка библиотек.
