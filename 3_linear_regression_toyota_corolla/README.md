# Линейная регрессия: цены на подержанные Toyota Corolla

**Файл:** `linear_regression_toyota_corolla.ipynb`  
**Источник данных:** [Kaggle: Price of Used Toyota Corolla Cars](https://www.kaggle.com/datasets/vishakhdapat/price-of-used-toyota-corolla-cars)

Предсказание стоимости подержанных автомобилей Toyota Corolla с помощью линейной регрессии и её регуляризованных вариантов (Ridge и Lasso).

## О данных

- **Размер:** 1436 записей, 39 столбцов;
- **Цель:** `Price`, цена автомобиля (регрессия);
- **Признаки:** возраст (`Age_08_04`), пробег (`KM`), мощность (`HP`), тип топлива, цвет, модель и ряд технических параметров и опций;
- **Пропуски:** отсутствуют.

Датасет загружается прямо из ноутбука через `kagglehub`, скачивать файл вручную не нужно.

## Что делается в ноутбуке

### 1. Первичный анализ (EDA)
- `head()`, `info()` и статистика по строковым столбцам, чтобы понять, как их преобразовывать;
- гистограмма цены: распределение скошено вправо, есть редкие дорогие автомобили (свыше 30 000).

### 2. Предобработка и работа с признаками
- удалены `Id` (не несёт смысла) и `Model` (более 300 уникальных значений, раздул бы размерность);
- 10 категорий цвета сгруппированы в один бинарный признак `Is_Basic_Color` (1 для серого, белого и чёрного);
- `Fuel_Type` закодирован через One-Hot Encoding (`drop_first=True`);
- масштабирование `StandardScaler` (обучается только на train), так как линейные модели чувствительны к разнице в масштабах (например, пробег в км и возраст в годах).

### 3. Разделение выборки
Разбиение 80/20 с `random_state=42`: 1148 автомобилей в обучении и 288 в тесте. Тест нужен для объективной оценки на данных, которые модель не видела.

### 4. Обучение моделей
Три модели на отмасштабированных данных:
- **Linear Regression** — классическая линейная регрессия;
- **Ridge** (`alpha=1.0`) — L2-регуляризация;
- **Lasso** (`alpha=1.0`) — L1-регуляризация, может занулять лишние признаки.

### 5. Оценка качества
Метрики на тестовой выборке:
- **MAE** — средняя абсолютная ошибка в евро;
- **RMSE** — чувствительнее к крупным ошибкам;
- **R²** — доля объяснённой дисперсии.

| Модель | MAE (евро) | RMSE | R² |
| :--- | :--- | :--- | :--- |
| Linear Regression | 822.62 | 1224.69 | 0.8876 |
| Ridge | 822.29 | 1223.60 | **0.8878** |
| Lasso | 822.14 | 1224.08 | 0.8877 |

Дополнительно построен график «реальные цены vs предсказанные» для Ridge: точки лежат близко к диагонали, значит предсказания хорошие.

## Выводы

- Все три модели показали практически одинаковый результат (R² около 0.89, средняя ошибка около 822 €). Небольшое преимущество у **Ridge** (самый низкий RMSE).
- Наибольшее влияние на цену оказывают **возраст автомобиля** и **пробег**.
- Группировка цветов и кодирование топлива сохранили информативность данных без избыточной размерности.
- Регуляризация почти не дала прироста, то есть сильного переобучения у обычной линейной регрессии нет.
