# Гауссовский наивный Байес с нуля и сравнение со scikit-learn

**Файл:** `naive_bayes_from_scratch.ipynb`  
**Данные:** `Iris` из `sklearn.datasets`

Реализация Гауссовского наивного Байеса (Gaussian Naive Bayes) «с нуля» на NumPy и сравнение с `sklearn.naive_bayes.GaussianNB`. Отдельно проверяется, насколько выполняется допущение о независимости признаков.

## О данных

- **Задача:** многоклассовая классификация (3 класса: `setosa`, `versicolor`, `virginica`);
- **Размер:** 150 объектов, 4 непрерывных признака (длина и ширина чашелистика и лепестка);
- **Классы:** сбалансированы, по 50 объектов;
- **Пропуски:** отсутствуют.

Датасет встроен в `scikit-learn`, скачивать ничего не нужно.

## Теория коротко

Для классификации выбирается класс с максимальной апостериорной вероятностью по правилу Байеса: `ĉ = argmax P(x | c) · P(c)`.

- **«Наивное» допущение:** признаки условно независимы при данном классе, поэтому `P(x | c) = ∏ P(x_j | c)`.
- **Гауссовское допущение:** внутри класса каждый признак распределён нормально, со своими средним и дисперсией.
- **Логарифмы:** чтобы произведение многих малых вероятностей не обнулилось, считается сумма логарифмов.

## Что делается в ноутбуке

### 1. Подготовка данных
- проверка пропусков, статистика, гистограммы признаков по классам;
- разбиение train/test 80/20 со стратификацией (`random_state=42`): 120 и 30 объектов;
- стандартизация не нужна: каждый признак моделируется отдельно со своими средним и дисперсией.

### 2. Реализация с нуля
- **`compute_priors`** — априорные вероятности классов `P(c) = n_c / n`;
- **`fit_gaussian_params`** — среднее и дисперсия каждого признака в каждом классе (массивы формы `(n_classes, n_features)`);
- **`gaussian_log_likelihood`** — логарифм плотности нормального распределения, с `eps = 1e-9` к дисперсии против деления на ноль;
- **класс `MyGaussianNB`** с методами `fit`, `predict_log_proba` (лог-прайор плюс сумма лог-правдоподобий по признакам) и `predict` (argmax).

### 3. Оценка качества
Метрики на тесте: accuracy, precision, recall, F1 (macro), confusion matrix и classification report.

### 4. Сравнение со scikit-learn

| Модель | Accuracy | Precision (macro) | Recall (macro) | F1 (macro) |
| :--- | :--- | :--- | :--- | :--- |
| Своя реализация | 0.9667 | 0.9697 | 0.9667 | 0.9666 |
| scikit-learn | 0.9667 | 0.9697 | 0.9667 | 0.9666 |

Метрики совпадают полностью, а оценённые средние (`theta_` в sklearn) совпадают с собственными до всех знаков.

### 5. Проверка допущения о независимости
Построены матрицы корреляций признаков внутри каждого класса. Признаки внутри классов заметно коррелируют (например, у `setosa` корреляция длины и ширины чашелистика около 0.78), то есть «наивное» допущение нарушается.

## Выводы

- Своя реализация даёт те же результаты, что и библиотечная: алгоритм реализован корректно.
- Допущение о независимости на Ирисах нарушается, но модель всё равно работает хорошо (accuracy около 0.97): для классификации важно правильно ранжировать классы, а не точно оценивать вероятности.
- Наивный Байес предпочтителен, когда данных мало, признаков много или важна скорость обучения. Логистическая регрессия лучше, когда признаки сильно зависимы.
