# Метод опорных векторов (SVM): Breast Cancer

**Файл:** `svm_breast_cancer.ipynb`  
**Данные:** `Breast Cancer Wisconsin` из `sklearn.datasets`

Исследование метода опорных векторов в задаче бинарной классификации: влияние масштабирования признаков, подбор гиперпараметров через `GridSearchCV`, визуализация границы решений, анализ ошибок и сравнение линейного и RBF-ядра.

## О данных

- **Задача:** бинарная классификация (`malignant` / `benign`);
- **Размер:** 569 объектов, 30 числовых признаков;
- **Классы:** 357 доброкачественных (1) и 212 злокачественных (0);
- **Пропуски:** отсутствуют.

Датасет встроен в `scikit-learn`, скачивать ничего не нужно.

## Теория коротко

SVM ищет гиперплоскость, максимизирующую зазор (margin) между классами. Ключевые параметры:

| Параметр | Влияние |
| :--- | :--- |
| `C` большой | узкий зазор, мало ошибок на train, риск переобучения |
| `C` малый | широкий зазор, допускает ошибки, лучше обобщение |
| `gamma` большой | сложная граница, переобучение |
| `gamma` малый | гладкая граница, недообучение |

RBF-ядро позволяет строить нелинейные границы без явного перехода в высокомерное пространство.

## Что делается в ноутбуке

### 1. EDA и разделение данных
- проверка пропусков, статистика, гистограммы признаков по классам;
- разбиение train/test 80/20 (`random_state=42`): 455 и 114 объектов.

### 2. Влияние масштабирования
`SVC(kernel='rbf', C=1.0)` без масштабирования и в `Pipeline` с `StandardScaler`. Pipeline защищает от утечки данных: скейлер обучается только на train (и внутри каждого фолда при кросс-валидации).

### 3. Подбор гиперпараметров
`GridSearchCV` (`cv=5`, `scoring='f1'`) по сетке:
- `C`: 0.01, 0.1, 1, 10, 100;
- `kernel`: linear, rbf;
- `gamma`: scale, 0.01, 0.1.

Лучшие параметры: `C=10`, `gamma=0.01`, `kernel='rbf'`, CV F1 = 0.9795.

### 4. Визуализация и анализ ошибок
- confusion matrix лучшей модели;
- граница решений на двух признаках (`mean radius`, `mean texture`) на train и test;
- разбор неверно классифицированных объектов теста.

### 5. Линейный и RBF SVM
Сравнение 5-fold кросс-валидацией на train (метрика F1):

| Модель | F1 (mean ± std) |
| :--- | :--- |
| LinearSVC | 0.9668 ± 0.0211 |
| RBF SVC | **0.9795 ± 0.0125** |

## Результаты на тесте

| Модель | Accuracy | Precision | Recall | F1 |
| :--- | :--- | :--- | :--- | :--- |
| Без масштабирования | 0.9474 | 0.9221 | 1.0 | 0.9595 |
| С масштабированием | 0.9825 | 0.9726 | 1.0 | 0.9861 |
| Лучшая после GridSearch | 0.9825 | 0.9726 | 1.0 | 0.9861 |

## Выводы

- Масштабирование признаков заметно улучшает качество SVM (accuracy 0.947 → 0.982): без него признаки с большими числами (например, `mean area`) доминируют в расстояниях.
- RBF-ядро стабильнее и точнее линейного по кросс-валидации.
- Лучшая модель ошиблась на 2 объектах теста: оба — злокачественные опухоли, предсказанные как доброкачественные. В медицинской задаче такой тип ошибки самый опасный, поэтому важно следить за recall по классу `malignant`.
- Подбор гиперпараметров на тесте дал тот же результат, что и модель с параметрами по умолчанию: выборка маленькая, и обе модели уже близки к потолку качества.
