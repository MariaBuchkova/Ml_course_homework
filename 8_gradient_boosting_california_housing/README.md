# Градиентный бустинг: XGBoost, LightGBM, CatBoost и своя реализация

**Файл:** `gradient_boosting_california_housing.ipynb`  
**Данные:** `California Housing` из `sklearn.datasets` (`fetch_california_housing`)

Сравнение трёх популярных библиотек градиентного бустинга (XGBoost, LightGBM, CatBoost) и собственной реализации `MyBoost` на задаче регрессии: подбор числа деревьев, подбор гиперпараметров, оценка качества и скорости обучения.

## О данных

- **Задача:** регрессия, предсказание медианной стоимости жилья в районе Калифорнии;
- **Размер:** 20 640 объектов, 8 числовых признаков (`MedInc`, `HouseAge`, `AveRooms`, `AveBedrms`, `Population`, `AveOccup`, `Latitude`, `Longitude`);
- **Разбиение:** train 60% (12 384), validation 20% (4 128), test 20% (4 128), `random_state=42`.

Датасет скачивается автоматически средствами `scikit-learn`.

## Что делается в ноутбуке

### 1. Выбор числа деревьев
Все три библиотеки обучаются с `n_estimators=1000` и `learning_rate=0.05`, а на валидации отслеживается RMSE по мере добавления деревьев. По графику выбрано `SELECTED_N_ESTIMATORS = 400`: дальше качество на валидации перестаёт заметно улучшаться.

### 2. Собственная реализация `MyBoost`
Градиентный бустинг для регрессии с квадратичной функцией потерь:
- начальное предсказание: среднее значение целевой переменной;
- на каждой итерации считается антиградиент (остатки `y − предсказание`), и на них обучается решающее дерево (`DecisionTreeRegressor`, `max_depth=7`, критерий `friedman_mse`);
- предсказание обновляется с шагом `learning_rate`;
- поддерживаются `subsample` (случайные строки) и `colsample_bytree` (случайные признаки для каждого дерева);
- считаются `feature_importances_`.

### 3. Подбор гиперпараметров
Перебор по сетке (`ParameterGrid`) с оценкой RMSE на валидации, по 8 комбинаций для каждой библиотеки:

| Модель | Лучшие параметры | Validation RMSE |
| :--- | :--- | :--- |
| XGBoost | `learning_rate=0.05`, `max_depth=7`, `subsample=0.8` | 0.4621 |
| LightGBM | `learning_rate=0.1`, `num_leaves=31`, `subsample=0.8` | 0.4557 |
| CatBoost | `learning_rate=0.1`, `depth=7`, `subsample=1.0` | 0.4564 |

### 4. Финальное сравнение
Модели переобучаются на train + validation с лучшими параметрами и оцениваются на тесте:

| Модель | Время обучения (с) | MAE | RMSE | R² |
| :--- | :--- | :--- | :--- | :--- |
| XGBoost | 4.77 | 0.2912 | 0.4476 | 0.8471 |
| **LightGBM** | **0.71** | **0.2862** | **0.4379** | **0.8537** |
| CatBoost | 2.65 | 0.2967 | 0.4493 | 0.8460 |
| MyBoost | 60.61 | 0.2957 | 0.4563 | 0.8411 |

## Выводы

- **LightGBM** оказался и самым точным, и самым быстрым (0.71 с, R² = 0.854).
- Все три библиотеки дают близкое качество: разница в RMSE около 0.01.
- Собственный `MyBoost` почти догоняет библиотечные модели по качеству (R² = 0.841), но обучается в десятки раз дольше (60 с против 0.7–4.8 с): в библиотеках деревья строятся оптимизированными алгоритмами на C++ с параллелизмом, а у `MyBoost` — обычные деревья `sklearn` без гистограммной оптимизации.
